# WynWin Website

Single-page marketing site built as a Design Component. Open `WynWin Website.dc.html` in the design tool to edit, or serve statically (needs `support.js` and the `_ds/` design-system folder alongside it).

Note: `assets/logo-wordmark.png` and `assets/logo-wordmark-white.png` are binary logo files not included in this text-only push — copy them in separately from the design system project.
